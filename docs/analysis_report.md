# 母婴零售用户行为分析报告

## 一、摘要

本报告基于 82 万条订单、26 万会员、162 万条访问记录，从用户画像、消费行为、时间分布、RFM 分层四个维度分析母婴零售业务特征。

**核心发现：**
1. **用户以女性为主**（86.7%），宝宝年龄段集中在 1-3 岁（49%）
2. **地域集中在下沉市场**：四线、三线城市为主，河南占比最高（28.7%）
3. **访问高峰在 10 点、15 点、20 点**，与育儿作息吻合
4. **销售波动大**：4 月、6 月、11 月是高峰，大促后必跌
5. **营销依赖特卖促销**（55%），其他活动占比低
6. **用户流失严重**：R=1（很久没买）用户占 76%

**建议：**
- 重点唤回"曾经忠诚但流失"的用户（R=1, F=5）
- 拓展备孕/孕期用户（当前仅占 0.22%）
- 平滑销售波动，减少大促依赖

---

## 二、背景与问题

母婴零售是高频、刚需、复购型业务。本报告旨在回答：
1. 谁在买？（用户画像）
2. 买什么？（商品/年龄段）
3. 什么时候买？（时间分布）
4. 怎么留住他们？（RFM 分层）

---

## 三、数据与方法

### 3.1 数据来源
- 订单表：82.6 万条
- 会员表：26.2 万条
- 访问表：162 万条

### 3.2 数据清洗
1. 日期转 datetime
2. 销售额转数字
3. 按订单号+商品编码去重
4. 派生年、月、日、星期字段

### 3.3 数据模型
- 事实表：orders、traffic
- 维度表：members

## 四、分析发现

### 4.1 用户画像：女性为主，1-3 岁宝宝是核心

| 维度 | 分布 |
|------|------|
| 性别 | 女 86.7%，男 13.3% |
| 宝宝年龄 | 1-3 岁 49.06%，3-6 岁 28.70%，6-14 岁 14.00% |
| 备孕/孕期 | 仅 0.22% |

**结论**：核心用户是"1-3 岁宝宝的妈妈"。

### 4.2 地域分布：下沉市场为主

| 省份 | 占比 |
|------|------|
| 河南 | 28.73% |
| 江苏 | 14.82% |
| 山东 | 13.22% |
| 四川 | 12.45% |

| 城市等级 | 特征 |
|----------|------|
| 四线 | 最大 |
| 三线 | 第二 |
| 新一线 | 较少 |

**结论**：用户集中在下沉市场。

### 4.3 访问时段：10 点、15 点、20 点高峰

**访问高峰**：
- 上午 10 点（127k）
- 下午 15 点（124k）
- 晚上 20 点（127k）

**结论**：与育儿作息吻合（宝宝睡觉时刷手机）。

### 4.4 销售趋势：波动大

| 月份 | GMV | 增长率 |
|------|-----|--------|
| 4 月 | 16.3M | +51.81% |
| 6 月 | 17.2M | +39.46% |
| 5 月 | 12.3M | -24.55% |
| 12 月 | 8.76M | -38.47% |

**结论**：大促后必跌，销售不稳定。

### 4.5 营销活动：特卖促销主导

| 活动 | 占比 |
|------|------|
| 特卖促销 | 55% |
| 福利秒杀 | 18% |
| 多人拼团 | 12% |
| 自然 | 9% |
| 活动报名 | 5% |

**结论**：依赖特卖促销，其他活动效果弱。

### 4.6 RFM 分层：流失严重

| R 分 | 用户数 | 占比 |
|------|--------|------|
| R=1 | 199k | 76% |
| R=2 | 33k | 13% |
| R=3 | 20.2k | 8% |
| R=4 | 7.15k | 3% |
| R=5 | 2.6k | 1% |

**结论**：76% 用户很久没买，流失严重。高价值用户（R≥4）仅 4%。

---

## 五、结论与建议

### 5.1 核心结论
1. 用户以女性、下沉市场、1-3 岁宝宝家长为主
2. 访问高峰在育儿空闲时段
3. 销售波动大，依赖大促
4. 用户流失严重，76% 很久没买

### 5.2 建议
1. **唤回流失用户**：对 R=1, F=5 的用户发定向优惠券
2. **拓展备孕用户**：当前仅 0.22%，是增量市场
3. **平滑销售**：减少大促依赖，做日常促销
4. **优化时段**：在访问高峰推送消息

### 5.3 数据局限
- 数据为 2021 年，时效性有限
- 会员画像只有性别和地域，缺年龄、收入
